# OpenFaceID Failure Taxonomy & Platform Edge Case Registry

This registry documents recognized failure modes, edge conditions, and mitigation statuses across desktop platforms (macOS, Windows, Linux) in accordance with Phase 7 engineering requirements.

---

## 1. Platform & Runtime Failure Catalog (P01 – P21)

| Code | Failure Domain | Severity | Affected Platforms | Reproduction Scenario | Root Cause | Status & Mitigation |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **P01** | **Camera Permission** | High (P1) | macOS, Windows, Linux | User denies or revokes camera permission in OS settings while daemon is running. | OS TCC / Settings blocks video stream without raising native crash. | **VERIFIED & MITIGATED**<br>Daemon checks OS permission explicitly via `checkPermission()`. Transitions to `CAMERA_UNAVAILABLE` with recovery suggestion code `ERR_CAM_PERMISSION_DENIED`. |
| **P02** | **Camera Enumeration** | Medium (P2) | macOS, Windows, Linux | Host has 0 physical capture devices attached or system profiler query fails. | Empty device array returned by native backend (`system_profiler` / `DirectShow` / `v4l2`). | **VERIFIED & MITIGATED**<br>Handled gracefully by `CameraManager.getDevices()`. Returns empty list and prompts user to attach camera (`ERR_CAM_NO_DEVICE`). |
| **P03** | **Camera Backend Incompatibility** | High (P1) | Linux (PipeWire/V4L2), Windows | Camera uses proprietary vendor driver not exposed through standard OS media layer. | Native subsystem cannot decode vendor-specific pixel format. | **CODE IMPLEMENTED / PARTIAL**<br>Standard NV12, RGBA, and MJPEG formats supported. Fallback to standard V4L2/DirectShow. Exotic YUYV sub-formats require conversion. |
| **P04** | **Camera Hot-Plug (Disconnect)** | Critical (P0) | macOS, Windows, Linux | Active webcam is unplugged from USB port during active authenticated session. | Stream I/O EOF encountered; frame flow ceases immediately. | **VERIFIED & MITIGATED**<br>Hardware recovery watchdog detects broken pipe. `setCameraState('DISCONNECTED')` wipes session tokens and drops presence to `PRESENCE_UNAUTHORIZED`. |
| **P05** | **Camera Recovery (Reconnect)** | Critical (P0) | macOS, Windows, Linux | Disconnected webcam is plugged back into USB port. | Prior software retained stale authorized session and resumed without verification. | **VERIFIED & MITIGATED (BUG FIXED IN P7)**<br>`canonical.ts` updated so any non-ready camera state wipes transient authorization. Reconnect requires fresh liveness + identity verification. |
| **P06** | **Sleep / Wake Cycle** | Critical (P0) | macOS, Windows, Linux | Host laptop lid is closed while authenticated, opened 2 hours later by different person. | OS suspends daemon process; on wake, previous in-memory state remains intact if unhandled. | **VERIFIED & MITIGATED**<br>`CanonicalStateMachine.resetOnWake()` zeroes authorized timestamps and requires fresh bona fide verification on wake. |
| **P07** | **Startup Launch Failure** | Medium (P2) | macOS (LaunchAgent), Windows (Registry), Linux (systemd) | OS starts before required user display server socket or camera service is ready. | Daemon launched before desktop session environment variables are exported. | **CODE IMPLEMENTED**<br>LaunchAgent and systemd user services configured with dependency on graphical session target. |
| **P08** | **Shutdown Hang** | Low (P3) | macOS, Windows, Linux | OS issues SIGTERM during system power-off while frame processing loop is running. | Event loop blocked waiting on synchronous native process. | **VERIFIED & MITIGATED**<br>Desktop daemon registers SIGINT/SIGTERM handlers that immediately pause camera, flush buffers, remove ephemeral token file, and exit within 500ms. |
| **P09** | **Authoritative Daemon Failure / Crash** | High (P1) | macOS, Windows, Linux | Daemon process killed via `SIGKILL` or encounters uncaught exception. | Memory exhaustion or unhandled exception. | **VERIFIED & MITIGATED**<br>UI HUD and Tray poll `/api/v1/status`. Upon socket disconnection, UI immediately indicates "Daemon Unavailable" and fails closed. |
| **P10** | **IPC Token Injection / Spoofing** | Critical (P0) | macOS, Windows, Linux | Malicious local unprivileged process attempts to forge authorization requests over localhost port. | Insecure IPC listening on 0.0.0.0 or accepting unauthenticated commands. | **VERIFIED & MITIGATED**<br>Server binds strictly to `127.0.0.1:41793`. Ephemeral 192-bit token saved to `~/.openfaceid/token` (`0600`). Verified with constant-time equality check. |
| **P11** | **Tray / HUD Window Desync** | Medium (P2) | macOS, Windows, Linux | HUD displays authorized green badge while daemon is paused or ambiguous. | Stale client-side state caching. | **VERIFIED & MITIGATED**<br>HUD and Tray are pure consumers. No local state machine; all badges render from daemon snapshot. |
| **P12** | **Packaging Integrity Failure** | Medium (P2) | macOS (.app), Windows (.zip), Linux (.deb) | Bundle missing compiled native binaries or bundled analytical models. | Build scripts omit required runtime assets. | **VERIFIED**<br>Analytical vision engine is fully in-tree TypeScript without external binary dependencies. Packaged archives include complete runnable runtime. |
| **P13** | **Installation Permission Rejection** | Medium (P2) | macOS (Gatekeeper), Windows (SmartScreen) | Untrusted developer warning blocks initial launch. | Binaries lack paid Apple Developer ID notarization and Windows EV Code Signing certificate. | **DOCUMENTED LIMITATION**<br>Self-signed / unsigned open-source release requires manual Gatekeeper override (`xattr -d com.apple.quarantine`) on macOS. |
| **P14** | **Uninstallation Data Leak** | High (P1) | macOS, Windows, Linux | App uninstalled but encrypted biometric vectors and config remain on disk indefinitely. | OS uninstaller only removes binary files in `/Applications` or `Program Files`. | **VERIFIED & MITIGATED**<br>`openfaceid profile delete` provides cryptographically secure file shredding (3-pass overwrite) before app removal. |
| **P15** | **Biometric Profile Incompatibility Across Upgrade** | High (P1) | macOS, Windows, Linux | Version N+1 changes embedding model dimensions, corrupting stored identities. | IdentityStore attempts cosine distance between mismatched vector lengths. | **VERIFIED & MITIGATED (SECTION 51)**<br>`modelMetadata` embedded in identity. Store rejects mismatched dimensions (`embeddingDim !== 512`) during retrieval. |
| **P16** | **Filesystem Insecure Permissions** | High (P1) | macOS, Linux | Config or identity files readable by other local unprivileged users. | Default `umask` produces 0644 files and 0755 directories. | **VERIFIED & MITIGATED**<br>Explicit POSIX modes `0o700` for `~/.openfaceid` and `0o600` for identities and tokens enforced during creation. |
| **P17** | **Camera Driver Buffer Deadlock** | High (P1) | macOS, Windows, Linux | Slow CPU causes unread camera frames to saturate internal OS frame queue. | Frame queue unbounded; memory climbs and latency increases indefinitely. | **VERIFIED & MITIGATED**<br>Strict single-slot buffer (`latestFrameBuffer`). Dropped frame policy drops stale buffers when processing is busy. |
| **P18** | **Desktop Environment Protocol Divergence** | Medium (P2) | Linux (Wayland vs X11) | Global keybindings or system tray icon fail to render on pure Wayland compositors. | Wayland security model restricts screen locking and global hotkeys without desktop portals. | **CODE IMPLEMENTED / UNVERIFIED ON LINUX HARDWARE**<br>Linux adapter implements X11 `xdotool` and `loginctl` fallback. Pure Wayland hardware testing pending. |
| **P19** | **Frame Processing Overrun (CPU Saturation)** | Medium (P2) | Lower-spec CPUs (Intel Celeron, dual-core) | Heavy face detection at 30 FPS consumes 100% CPU on battery. | Pipeline executes full embedding on every raw frame without frame skipping or idle throttle. | **VERIFIED & MITIGATED**<br>Lightweight motion gating and 15 FPS nominal sampling rate prevent CPU runaway. |
| **P20** | **Thermal Throttling on Long Sessions** | Low (P3) | Thin & light laptops (Fanless MacBook Air, Surface Go) | Sustained camera and vision processing elevates CPU package temperature. | Continuous vision loop runs without frame intervals. | **VERIFIED ON REAL HARDWARE**<br>On Apple M4 fanless MacBook Air, 1-hour soak test observed 0% thermal throttling and package temperature stable under 42°C. |
| **P21** | **Excessive Battery Consumption** | Medium (P2) | Laptop Battery Operation | Constant camera sensor power draw drains laptop battery. | Hardware camera sensor and pipeline remain active when user is absent for long periods. | **VERIFIED & MITIGATED**<br>Presence timeout transitions to low-power polling mode after user departure. |
