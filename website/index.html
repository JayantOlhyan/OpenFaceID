Installation

Requirements:

  • macOS 15 Sequoia or later
  • Apple Silicon or Intel Mac

Open the .dmg file and drag OpenFaceID to /Applications , then open it.

Requirements:

  • Windows 10 or Windows 11 (64-bit)
  • DirectShow or MediaFoundation compatible webcam

Open the .zip file, extract OpenFaceID, then run OpenFaceID.cmd.

Requirements:

  • Ubuntu 22.04+, Debian 12+, Fedora 38+, or Arch Linux
  • V4L2-compatible video capture device (/dev/video0)

Open the .deb file and install with sudo dpkg -i , then open it from your app launcher.

Seamless Installation

1

Download Package

Download the release image for your operating system (macOS DMG, Windows ZIP, Linux DEB).

2

Install & Launch

Open the package and drag or install into system Applications or run the launcher command.
