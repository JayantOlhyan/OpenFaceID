Engineered for Privacy & Presence

Dynamic Presence Awareness

Continuous optical monitoring tracks presence with 5 canonical states: Authorized, Absent, Multiple People, Unknown Person, and Privacy Paused with real-time beacons.

Zero-Touch Lock-on-Leave

Automatically secures your workstation via native macOS screen lock the moment you step away, with configurable departure timeouts from 5 to 60 seconds.

Fail-Closed Biometrics

If multiple faces appear in the camera field, liveness fails, or the camera is obscured, authorization immediately drops to fail-closed state (PRESENCE_AMBIGUOUS).

Zero Cloud Egress

100% on-device volatile RAM processing. Biometric vectors are encrypted with AES-256-GCM. Deleting profiles performs a multi-pass cryptographic shred.

Native macOS Experience

Native Swift Cocoa launcher with menu bar supervision, Dark Mode HIG styling, floating Quick Glance HUD, and dedicated AVFoundation camera helper.

No Keystroke / Password Capture

OpenFaceID operates strictly at the presence layer. We never capture, store, or simulate macOS user passwords or accessibility keystrokes.

Installation

Requirements:

  • macOS 15 Sequoia or later
  • Apple Silicon or Intel Mac

Open the .dmg file and drag OpenFaceID to /Applications , then open it.

Requirements:

  • Windows 10 or Windows 11 (64-bit)
  • DirectShow or MediaFoundation compatible webcam

Open the .zip file, extract OpenFaceID, then run OpenFaceID.cmd.

Requirements:

  • Ubuntu 22.04+, Debian 12+, Fedora 38+, or Arch Linux
  • V4L2-compatible video capture device (/dev/video0)

Open the .deb file and install with sudo dpkg -i , then open it from your app launcher.
